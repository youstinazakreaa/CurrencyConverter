# Currency Converter - Singleton Design Pattern
A simple C# Console Application that demonstrates the Singleton Design Pattern through a currency converter.
## About the Project

This project is a simple Currency Converter built with C# as a Console Application.

The main goal of the project is to practice and demonstrate the Singleton Design Pattern by ensuring that only one instance of the currency converter is created and used throughout the application.

## Features

- Convert an amount from one currency to another
- Support multiple currencies such as USD, EUR, and GBP
- Use predefined exchange rates
- Apply the Singleton Design Pattern
- Ensure that only one instance of the currency converter is created
- Use a thread-safe Singleton implementation

  ## Technologies Used

- C#
- .NET
- LINQ
- Singleton Design Pattern
## Singleton Implementation

The Currency Converter uses the Singleton Design Pattern to ensure that only one instance of the converter is created during the application lifecycle.

A private constructor prevents direct object creation, while a static instance provides global access to the same object.
